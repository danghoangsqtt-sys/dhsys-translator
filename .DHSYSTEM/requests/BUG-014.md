# BUG-014 — Docker build context can include local API configuration

- Type: BUG
- Priority: P0
- State: verified and persisted
- Source: dh-audit follow-up 2026-10-04
- References: Dockerfile:60; .dockerignore; videotrans/configure/_app_params.py:32

## Evidence

COPY . . includes local videotrans/params.json and cfg.json because .dockerignore omits them; both files exist locally, and settings can contain API credentials.

## Acceptance

Build context and image exclude config, .env, keys and user data; a seeded dummy secret is absent from image layers.

## Re-check 2026-10-04

`.dockerignore` excludes config, environment files, key formats and local output. A scratch image built from the actual context contained application source but no dummy `.env.dh-task34-probe`, `videotrans/params.json`, or `videotrans/cfg.json`. The temporary image and workspace probe were removed. The repair is persisted on `origin/main`.
