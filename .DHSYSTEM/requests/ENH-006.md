# ENH-006 — Làm mới README và bổ sung ảnh giao diện

- State: complete
- Priority: P1
- Created: 2026-10-07

## Mục tiêu

Viết lại toàn bộ `README.md` để phản ánh đúng sản phẩm pyVideoTrans-DH phiên bản 4.14 hiện tại, hướng dẫn người dùng Việt Nam bắt đầu nhanh, trình bày trung thực trạng thái kiểm thử/phân phối và dùng ảnh chụp từ giao diện Qt đang chạy trong codebase.

## Phạm vi

1. Thay nội dung README cũ thiên về upstream bằng tài liệu Việt-first cho fork `dhsys-translator`.
2. Mô tả đúng giao diện Việt/Anh, luồng năm bước, công cụ kiểm tra máy, CLI/WebUI, cách chạy từ source và bản Windows.
3. Tạo ảnh chụp có thể tái lập từ giao diện ứng dụng hiện tại; lưu asset trong repository và không để lộ khóa, media hay đường dẫn riêng tư.
4. Nêu rõ giới hạn phát hành: version manifest vẫn là 4.14, gói Setup chưa ký số và kiểm thử máy Windows sạch vẫn là cổng mở.
5. Kiểm tra liên kết, ảnh, định dạng Markdown và hồi quy liên quan trước khi đẩy lên `origin/main`.

## Điều kiện nghiệm thu

- `README.md` không còn liên kết clone hoặc nhận diện chính gây nhầm sang repository upstream.
- Ảnh README được tạo từ widget Qt hiện tại, hiển thị được trong GitHub và không chứa dữ liệu riêng tư.
- Lệnh cài/chạy/test khớp `pyproject.toml`, entry point và tài liệu dự án hiện hành.
- Trạng thái kiểm thử và phát hành được mô tả có giới hạn, không tuyên bố hoàn tất cổng clean-machine khi chưa có bằng chứng.
- Thay đổi được commit và push thành công tới `https://github.com/danghoangsqtt-sys/dhsys-translator`.

## Ngoài phạm vi

- Tăng version, tạo GitHub Release hoặc tải gói Windows dung lượng lớn lên Releases.
- Đóng cổng ENH-005 task 5.5 hay Phase 3 task 3.3 khi chưa có kiểm thử máy sạch.
- Thay đổi hành vi xử lý video, provider/model ID hoặc cấu hình người dùng.
