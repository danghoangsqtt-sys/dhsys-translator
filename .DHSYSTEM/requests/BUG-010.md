# BUG-010 — Desktop --lang short codes fall back to OS locale

- Type: BUG
- Priority: P2
- State: verified and persisted
- Local verification: subprocess desktop imports with `--lang en`, `zh`, and `zh-cn` select the requested locale despite opposite environment defaults.
- Source: dh-audit 2026-10-04
- References: sp.py:134-137; videotrans/configure/_i18n.py:43-53

## Evidence

Static mismatch: CLI advertises en/zh but i18n keys use en_US/zh_CN.

## Acceptance

--lang en and --lang zh select requested UI language independent of OS locale.
