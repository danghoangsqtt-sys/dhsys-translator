# BUG-007 — PyInstaller may omit dynamically imported providers

- Type: BUG
- Priority: P1
- State: open
- Local verification: Python 3.12 PyInstaller produced an onedir artifact; resources and FFmpeg layout were inspected and offscreen startup passed. Clean-runner and packaged dynamic-provider/media smoke remain open.
- Source: dh-audit 2026-10-04
- References: sp.spec:75-100; videotrans/__init__.py:27-29; videotrans/winform/__init__.py:29-55

## Evidence

Static risk: dynamic importlib names are absent from spec's explicit hidden imports.

## Acceptance

Inspect collected modules and run one dynamic provider and dialog in packaged artifact.

## Re-detected 2026-10-04 — executable smoke

Running `sp.exe` with a minimal external probe from the previous Python 3.12 onedir artifact exited before the probe ran. Captured stderr shows `pyi_rth_pkgres.py` importing `pkg_resources` and failing with `ModuleNotFoundError: No module named 'jaraco.text'`. The package had no usable provider/dialog smoke yet. Keep the request open while correcting `sp.spec` and rebuilding.

During rebuild, PyInstaller also reported `Hidden import 'videotrans.recognition._faster_whisper' not found`. The provider registry actually maps the faster-whisper channel to `videotrans.recognition._whisper`; the spec and executable smoke were corrected to use that module. Rebuild and invoke the provider from the artifact before closing this request.

The rebuilt artifact now enters the smoke script and successfully reaches the dynamic dialog call, but `get_win('chatgpt')` fails because `videotrans.ui.chatgpt` is absent. The spec includes `videotrans.winform.chatgpt` but must also include its dynamically loaded UI class. A new rebuild and executable smoke are required.

## Local artifact verification 2026-10-04

The Python 3.12.13 onedir rebuild passed an executable smoke both before and after ZIP extraction. The extracted bundle dynamically resolved `videotrans.recognition._whisper` and `videotrans.translator._google`, opened the `chatgpt` dialog, ran `cli.py --version` (`4.14`), parsed SRT and generated an MP4 with audio and video. The CLI probe also exposed an excluded standard-library `pdb` dependency in PyTorch; the spec no longer excludes standard-library modules. Keep this request open until the candidate workflow repeats these checks on a clean Windows runner and Git persistence is resolved.
