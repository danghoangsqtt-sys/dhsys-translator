# BUG-005 — GUI shutdown terminates unrelated FFmpeg processes

- Type: BUG
- Priority: P1
- State: verified locally and persisted; packaged GUI-close acceptance pending
- Source: dh-audit 2026-10-04
- References: videotrans/mainwin/_lifecycle.py:29-55,128

## Evidence

Static evidence: taskkill/pkill targets every ffmpeg process for the current user.

## Acceptance

Closing GUI stops only child processes owned by this app; unrelated render continues.

## Re-check 2026-10-04

`LifecycleMixin` now selects FFmpeg descendants via `psutil` rather than using user-wide process-name commands. Mock tests and a live probe confirmed an owned FFmpeg stopped while separate PID 17904 continued; the probe was cleaned up. Full suite 539 passed and the repair is persisted. Packaged GUI-close acceptance remains open.
