# ENH-002 — Responsive layout and light-theme parity for home and core tools

- Type: ENH
- Priority: P1
- State: open
- Source: dh-audit UI review, 2026-10-04
- References: `videotrans/ui/home.py`, `videotrans/ui/fn_fanyisrt.py`, `videotrans/ui/fn_peiyinrole.py`, `videotrans/ui/fn_vas.py`, `videotrans/ui/fn_recogn.py`, `videotrans/ui/workspace_shell.py`, `videotrans/language/vi_VN.json`

## Evidence

The repaired workspace now wraps its five configuration rows and replaces the sidebar with a compact menu below 980 px. Its current Vietnamese workspace labels resolve correctly.

Three user-facing layout problems remain outside that shell:

1. `HomePage` keeps a two-column `QGridLayout` and disables its horizontal scrollbar. In an offscreen 480 px-wide window, its second cards begin at x=339 and extend to x=688, outside the visible canvas. The welcome screen therefore clips its right column instead of changing to one column.
2. The four main shortcuts still impose desktop-only minimum widths: Translate SRT 1150 px with a fixed size policy, Multiple speakers 1200 px, Speech recognition 1200 px, and Merge video/audio/SRT 1000 px. Their rows also use unwrapped `QHBoxLayout` controls. They can exceed a small laptop window even though the main workspace no longer does.
3. Multiple speakers overrides the shared light stylesheet with a dark table, dark borders and a yellow label. The compact navigation key `Menu` has no Vietnamese translation and falls back to English.

## Acceptance

- Preserve all existing object names, signal connections, QAction routes, settings and media behavior.
- At narrow desktop widths, the home-page quick-tool cards and action buttons fit the visible canvas without clipping; use a single-card layout or another responsive arrangement.
- The four core tool windows fit narrow desktop widths through wrapping, scrolling or splitter behavior appropriate to each tool. No control needed to start, select files, or open output may be unreachable.
- Remove or adapt the dark local overrides in Multiple speakers so its table, labels and selected state follow the approved light palette (`#FFFFFF`, neutral grays, `#14452F`) with readable contrast.
- Add the Vietnamese `Menu` translation and verify the compact navigation in Vietnamese.
- Add source and frozen UI probes at 480 px, 720 px, 900 px and 1280 px. Keep the existing full regression and packaged smoke gates.
