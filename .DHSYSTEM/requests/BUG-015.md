# BUG-015 — Nonempty model file is accepted as a complete download

- Type: BUG
- Priority: P1
- State: verified and persisted
- Source: dh-audit follow-up 2026-10-04
- References: videotrans/util/help_down.py:204-210

## Evidence

Reproduced: a one-byte weights.bin makes down_file_from_hf return True without requesting the URL.

## Acceptance

Cache validation checks expected hash or size/format; corrupt file is re-downloaded atomically.

## Re-check 2026-10-04

One-byte cached and one-byte remotely reported model files are rejected; SHA-256/size metadata and a format-specific minimum guard are checked before atomic replace. Truncated/wrong-hash transfers preserve the prior file. A small local HTTP download and offline sidecar reuse passed; focused 7/full 546 tests passed. The repair is persisted on `origin/main`.
