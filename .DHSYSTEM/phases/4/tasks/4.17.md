# Task 4.17 — Controlled provider reduction and migration

## Scope

- Inventory providers, model lists, package dependencies and saved settings by actual data plane: local, Google, OpenRouter-compatible and other cloud.
- Implement hide/deprecate behavior only after profile parity, migration and regression evidence.
- Decide separately whether the policy excludes China-hosted APIs only or also locally executed China-origin open models.

## Acceptance

1. No provider is deleted until every persisted ID/configuration has an explicit migration or compatibility behavior.
2. UI removal does not remove Chinese media-language support.
3. Local-only profile functions with network disabled.
4. Documentation identifies which profile transmits media/text off-device.
