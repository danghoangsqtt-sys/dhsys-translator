## Acceptance

1. Original SRT text remains unchanged by pronunciation preparation.
2. Glossary overrides have deterministic, testable precedence.
3. Benchmark reports pronunciation accuracy, naturalness, voice continuity and duration alignment; it does not claim universal quality.
4. Pilot failure leaves Edge TTS and the current output workflow usable.
5. No private key, reference audio or local path is emitted into logs/artifacts.
6. Local VieNeu voice discovery is opt-in/loopback-only, preserves saved roles/settings on failure, and the main UI can retain a selected discovered voice.
7. Per-speaker role assignment can use different VieNeu voices without mutating the displayed/persisted subtitle text.
