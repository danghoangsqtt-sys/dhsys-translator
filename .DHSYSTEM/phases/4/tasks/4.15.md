# Task 4.15 — Simplify navigation and add provider profiles

Status: `in_progress`

## Objective

Make the basic desktop surface task-oriented without deleting or renumbering any provider or legacy QAction. Add three reversible configuration profiles that explain local/remote behavior, quota and privacy before changing settings, while preserving a user's previous custom provider choices for restoration.

## Compatibility boundary

- Provider numeric IDs, list order and persisted fields remain unchanged.
- All existing QAction objects and advanced settings remain reachable.
- Profiles apply existing settings; they do not replace provider registries or silently delete credentials/configuration.
- Local/basic navigation works with no cloud credential and Chinese media-language support remains intact.

## Execution notes

- 2026-10-05: task entered `in_progress` after Task 4.14 verification and persistence completed; navigation/provider persistence survey is next.

## Scope

- Keep the basic sidebar to five media jobs and one advanced entry.
- Keep provider configuration out of “All tools”; expose it through profiles/settings.
- Implement profiles `Miễn phí trên máy`, `Gemini API (quota miễn phí)` and `Tùy chỉnh nâng cao` as configuration presets, not replacement provider indices.
- Show privacy, quota and fallback hints when a remote profile is selected.

## Acceptance

1. Every existing QAction remains reachable, but the basic surface shows only task-oriented actions.
2. Switching profile never changes or corrupts existing provider IDs in saved settings.
3. A user can restore the prior custom configuration after trying a profile.
4. Basic interface works without configured cloud credentials.
