# Task 4.15 — Simplify navigation and add provider profiles

## Scope

- Keep the basic sidebar to five media jobs and one advanced entry.
- Keep provider configuration out of “All tools”; expose it through profiles/settings.
- Implement profiles `Miễn phí trên máy`, `Gemini API (quota miễn phí)` and `Tùy chỉnh nâng cao` as configuration presets, not replacement provider indices.
- Show privacy, quota and fallback hints when a remote profile is selected.

## Acceptance

1. Every existing QAction remains reachable, but the basic surface shows only task-oriented actions.
2. Switching profile never changes or corrupts existing provider IDs in saved settings.
3. A user can restore the prior custom configuration after trying a profile.
4. Basic interface works without configured cloud credentials.
