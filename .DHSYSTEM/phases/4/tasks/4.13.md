# Task 4.13 — Make subtitle correction operable and readable

Status: `PASS`

## Objective

Both recognition subtitle dialogs behave like normal editors: users can focus, select and edit cells with mouse or keyboard, see a high-contrast editing/selection state, understand whether changes are unsaved, and decide explicitly whether to save or continue without saving. ## Best practices

- Preserve the existing SRT and task-control contracts; keep presentation behavior in widgets/mixins and media logic outside them.
- Use standard Qt item-view flags and edit triggers instead of custom mouse event handling.
- Block item signals while populating rows so initial rendering is not treated as a user edit.
- Avoid hard-coded dark colors in light dialogs and make focus/selection visible.
- Keep all paths repository-relative and do not touch unrelated working-tree changes.
