# Task 10.3 — Step 3 progress and batch results

## Objective

Start jobs through the existing path and show per-stage progress, Stop, and the Phase 9 result panel for single and batch jobs.

## Paths

```text
videotrans/ui/wizard/step_run.py
videotrans/ui/workflow_state.py
videotrans/mainwin/_actions_task.py
tests/test_wizard_run.py
```

## Work

- Start calls `win_action.check_start` after applying wizard params; errors from the check return the user to the step that needs fixing.
- Progress list per stage (Nhận dạng, Dịch, Đọc giọng, Ghép) driven by `workflow_state` events; overall bar; Stop uses the existing stop action.
- Single job: embed `ResultPanel` on completion. Batch: list of videos with state; selecting a finished row loads its receipt into the panel.
- "Dịch video khác" resets to Step 1 keeping language/voice/caption choices.

## Verification

```powershell
uv run --python 3.12 pytest -q tests/test_wizard_run.py tests/test_workflow_state.py tests/test_result_panel.py
uv run --python 3.12 pytest -q
```

## Acceptance

- A real short media job started from the wizard produces the same output files as the classic workspace with the same params.
- Stop leaves the UI usable and marks the job stopped.
