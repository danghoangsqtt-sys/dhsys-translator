# Task 10.1 — Wizard shell and classic toggle

## Objective

Add the wizard container as the default start route and a persisted `ui_mode` switch between wizard and classic workspace.

## Paths

```text
videotrans/ui/wizard/__init__.py
videotrans/ui/wizard/shell.py
videotrans/ui/workspace_shell.py
videotrans/configure/_app_params.py
videotrans/mainwin/main_win.py
videotrans/language/vi_VN.json
videotrans/language/en_US.json
tests/test_wizard_shell.py
tests/test_app_params.py
```

## Work

- `WizardShell(QWidget)`: stepper header, `QStackedWidget` with three placeholder pages, Back/Next/Start footer, step validation hooks.
- Register the wizard as a `WorkspaceShell` route; select it on start when `ui_mode == "wizard"`.
- Add a "Giao diện cũ" / "Classic workspace" action in the wizard header and "Giao diện có hướng dẫn" in the classic sidebar; persist `ui_mode`.
- Default `ui_mode` to `wizard` when the key is missing.

## File-Level Plan

- `videotrans/ui/wizard/shell.py` — container and step navigation only.
- `videotrans/ui/workspace_shell.py` — route registration and toggle.
- `videotrans/configure/_app_params.py` — `ui_mode` default and validation (`wizard`|`classic`).
- `videotrans/mainwin/main_win.py` — initial route selection.
- `tests/test_wizard_shell.py` — default mode, toggle persistence, Back/Next enablement.

## Implementation Notes

- Routing lives in `MainWindow.page_stack` (Home page, then `WorkspaceShell`), not inside `WorkspaceShell`. The wizard is added as a third page of that stack; `MainWindow.show_wizard()` / `show_classic()` switch pages and persist `ui_mode`, and `_setup_home()` opens the wizard when `ui_mode == "wizard"`, otherwise the existing Home page (the classic start).
- `WizardShell` (`ui/wizard/shell.py`): stepper header (three step buttons with `stepState` = done/active/todo for QSS), a "Giao diện cũ" button emitting `classic_requested`, a `QStackedWidget` with three placeholder pages (filled by 10.2/10.3), Back/Next/Start footer, `set_step_validator(index, fn)` hooks that gate Next/Start and forward jumps, and a `start_requested` signal. Pure presentation; no params or media logic.
- `WorkspaceShell` gets a "Giao diện có hướng dẫn" sidebar button and the same action in the compact menu; both call `main_window.show_wizard()` when available.
- `_app_params.py`: `ui_mode` default `"wizard"`; saved values other than `wizard`/`classic` are ignored (fall back to the default), like `subtitle_type`.
