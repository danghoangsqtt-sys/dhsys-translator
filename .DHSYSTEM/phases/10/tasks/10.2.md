# Task 10.2 — Step 1 (video + purpose) and Step 2 (options)

## Objective

Implement the first two wizard pages so a user can choose videos, a purpose, languages, a voice and a caption style, with every technical control available under "Nâng cao".

## Paths

```text
videotrans/ui/wizard/step_video.py
videotrans/ui/wizard/step_options.py
videotrans/ui/wizard/presets.py
videotrans/ui/wizard/adapter.py
videotrans/ui/provider_visibility.py
videotrans/mainwin/main_win.py
videotrans/mainwin/_bind_signals.py
videotrans/language/vi_VN.json
videotrans/language/en_US.json
tests/test_wizard_steps.py
```

## Work

- Step 1: drop zone + chooser (multi-select), file rows with duration/resolution via existing ffprobe helpers, remove button, output folder line, three purpose tiles.
- `presets.py`: pure mapping purpose → existing params (`subtitle_type`, `tts_type`/voice off, output SRT only); returns a dict, never writes params itself.
- Step 2: source/target language combos (existing language lists), voice tiles filtered to the target language with "Nghe thử", caption style tiles (Cổ điển / Không có now; animated styles added in 11.3), summary card with cost category and estimate, collapsible "Nâng cao" hosting existing recognition/translation/alignment/separation controls.
- Validation: Next disabled until at least one readable video; Start disabled until languages are set.

## File-Level Plan

- `step_video.py`, `step_options.py` — pages; read/write params through one adapter function.
- `presets.py` — testable mapping.
- `ListenVoice.py` — reuse; add a non-blocking call path if the current one blocks the UI thread.
- `provider_visibility.py` — expose the access category for the summary card.
- `tests/test_wizard_steps.py` — preset mapping, validation, params round-trip, Advanced section contains existing controls.

## Implementation Notes

- **Single source of truth:** `check_start` and all existing handlers read the classic main-window widgets. `adapter.py` therefore drives those widgets instead of writing params: `set_videos()` fills `win_action.queue_mp4`, the purpose preset calls the existing `set_biaozhun()` / `set_tiquzimu()` and sets `subtitle_type` / `voice_role`, and `ComboMirror` / `CheckMirror` show synced copies of existing combos and checkboxes (items, hidden provider rows, current index; rebuilt when the source model changes, e.g. the voice list after a target-language change). Changing a mirror sets the source widget, so `set_voice_role`, `tts_type_change`, `recogn_type_change` and provider-profile marking keep working.
- **Step 1:** drop zone + **Chọn video** (multi-select, same extensions as `get_mp4`), rows with duration and resolution from `get_video_info`, remove buttons, output folder line (**Đổi**), three purpose tiles. Probing is injectable for tests.
- **Step 2:** source/target language mirrors; voice selector (a mirror of `voice_role`, because a voice list can be long) with **Nghe thử** calling the existing non-blocking `listen_voice_fun` (`ListenVoice` is already a `QThread`, so `util/ListenVoice.py` needs no change); subtitle tiles bound to `subtitle_type` (Phụ đề cứng 1, Phụ đề mềm 2, Song ngữ 3, Không có 0; animated styles come in 11.3); a summary card (cost from `provider_access`: "0 đ · không cần API key" when nothing needs a key; total video duration instead of a speed estimate, which would be a guess); a collapsible **Nâng cao** with mirrors of recognition provider/model, translation provider, TTS provider, voice speed-up, video slow-down, keep background sound and CUDA, plus **Tất cả tùy chọn** opening the classic workspace without changing `ui_mode`.
- **Wiring:** `MainWindow._attach_wizard_pages()` runs at the end of `_bind_signal()` (after `win_action` exists and defaults are loaded) and installs both pages plus validators: Step 1 needs ≥1 existing file; Step 2 needs a target language unless the purpose is "Chỉ tạo SRT".
