# Task 8.1 — Narrow curated provider policy

## Objective

Reduce `CURATED_PROVIDER_IDS` and `CURATED_MENU_ACTIONS` to the Phase 8 default visibility contract, label saved hidden selections, and move the show-all switch into Advanced settings without changing any provider ID or persisted key.

## Paths

```text

videotrans/ui/_setup_menus.py
videotrans/ui/workspace_shell.py
videotrans/language/vi_VN.json
videotrans/language/en_US.json
tests/test_provider_visibility.py
```

## Work

- Remove DeepSeek, Azure GPT, DeepL, Deepgram, ElevenLabs (STT/TTS) and Azure TTS from the curated sets and matching menu actions.
- Add a "(ẩn)" / "(hidden)" suffix for a selected provider that is outside the curated set while show-all is off.
- Relocate the `show_all_providers` action to an Advanced settings section; keep its object name, checkable state and params key.

## File-Level Plan

- `videotrans/ui/provider_visibility.py` — update the curated frozensets and menu-action allowlists; add a pure helper that returns the display suffix for hidden-but-selected rows.
- `videotrans/ui/_setup_menus.py` — attach `show_all_providers` to the Advanced section instead of the provider menu; keep the `set_show_all` handler.
- `videotrans/ui/workspace_shell.py` — show the Advanced entry point in provider settings so the switch stays reachable from the workspace.
- `videotrans/language/vi_VN.json`, `en_US.json` — add strings for the hidden suffix and Advanced section.
- `tests/test_provider_visibility.py` — assert the new curated sets, unchanged registries, hidden-selected suffix and show-all restoration.

## Best Practices

- Keep row hiding through `QAbstractItemView.setRowHidden()`; never rebuild a shorter combo list.
- Do not import application params into the policy module.
- Keep cost wording categorical; no prices or quota promises.
