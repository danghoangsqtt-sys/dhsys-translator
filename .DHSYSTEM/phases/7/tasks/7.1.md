# Task 7.1 — Provider visibility and cost policy

## Objective

Create one presentation-only policy that classifies providers by access/cost model and exposes a curated Viet Nam/global subset without deleting, renumbering or mutating any provider registry entry. Qt combo boxes must retain their original row indexes, and a saved provider outside the curated subset must remain visible while selected.

## Paths

```text
videotrans/ui/provider_visibility.py
videotrans/translator/_constants.py
videotrans/recognition/_constants.py
videotrans/tts/_constants.py
tests/test_provider_visibility.py
```

## Work

- Define curated Việt Nam/global provider IDs and visible settings actions by STT/translation/TTS.
- Define stable cost/readiness categories without volatile numeric price claims.
- Hide rows through the Qt view so numeric indexes remain unchanged.
- Keep the currently selected legacy provider visible.

## File-Level Plan

- `videotrans/ui/provider_visibility.py` — add the shared provider kinds, curated ID/action allowlists, cost/readiness metadata and Qt row-visibility helpers; keep this module presentation-only.
- `videotrans/translator/_constants.py` — consume existing translation IDs as immutable compatibility anchors; no registry reorder or deletion is allowed.
- `videotrans/recognition/_constants.py` — consume existing recognition IDs as immutable compatibility anchors; no registry reorder or deletion is allowed.
- `videotrans/tts/_constants.py` — consume existing speech IDs as immutable compatibility anchors; no registry reorder or deletion is allowed.
- `tests/test_provider_visibility.py` — freeze all registry mappings and verify curated, show-all and saved-hidden-selection behavior.

## Best Practices

- Keep provider availability separate from provider visibility.
- Address combo rows by their frozen numeric provider IDs; never rebuild a shortened list.
- Use `QAbstractItemView.setRowHidden()` so persisted numeric indexes remain valid.
- Keep cost wording categorical and stable; do not embed prices, quotas or promises of unlimited free access in code.
- Avoid importing application parameters into the policy module so it remains deterministic and easy to test.
