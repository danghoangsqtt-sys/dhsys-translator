# Task 7.2 — Desktop filtering and free-first profile

## Objective

Apply the shared visibility policy to every desktop provider entry point, persist one synchronized show-all preference, and add a no-API-key recommended profile that selects faster-whisper, Google translation and Edge-TTS without changing provider IDs or credentials.

## Work

- Filter all desktop provider entry points with one policy.
- Add synchronized, persisted **Show all providers** actions.
- Add a recommended no-key profile using faster-whisper, Google translation and Edge-TTS.
- Do not mutate credentials or provider IDs when switching visibility.

## File-Level Plan

- `videotrans/ui/_setup_menus.py` — retain every QAction but hide non-curated settings actions by default; add synchronized checkable “Show all providers” actions.
- `videotrans/ui/workspace_shell.py` — expose the recommended profile and refresh provider-menu copies when visibility changes.
- `videotrans/ui/provider_profiles.py` — define the no-key profile with the existing 0/0/0 provider IDs and deterministic policy disclosure.
- `videotrans/mainwin/main_win.py` — apply row hiding only after saved indexes are restored; centralize show-all persistence and refresh all registered provider combos/actions.
- `videotrans/winform/fn_fanyisrt.py` — register/apply translation visibility to the quick translation combo after restoring its saved index.
- `videotrans/winform/fn_recogn.py` — register/apply recognition visibility to the quick transcription combo after restoring its saved index.
- `videotrans/ui/fn_peiyin.py` — apply the TTS visibility policy to the single-speaker quick tool.
- `videotrans/ui/fn_peiyinrole.py` — apply the TTS visibility policy to the multi-speaker quick tool.
- `videotrans/configure/_app_params.py` — persist `show_all_providers`; use the no-key profile for fresh settings only while retaining existing saved profile values.
- `tests/test_provider_visibility.py` — cover menus, synchronization and persisted hidden selections.
- `tests/test_provider_profiles.py` — cover no-key profile selection, privacy policy and credential preservation.

## Best Practices

- Never remove actions or combo rows; only change presentation visibility.
- Restore saved indexes before applying the curated filter.
- Keep the selected legacy provider visible in every combo.
- Block signals while synchronizing checkable actions to avoid duplicate writes.
- Use one application preference and one refresh method for all surfaces.
- Do not call a network service or validate credentials while changing visibility.
