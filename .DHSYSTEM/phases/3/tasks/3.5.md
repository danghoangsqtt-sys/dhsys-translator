- BUG request files: append evidence, leave open until Git persistence gate passes.

## Best practices

- Never call `rmtree` on user-controlled paths without resolving and checking containment.
- Use `mkdir(exist_ok=False)` as the reservation primitive; avoid check-then-create races.
- Keep output naming predictable and preserve existing files; do not overwrite completed exports.
