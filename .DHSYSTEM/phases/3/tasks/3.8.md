Priority: P1. Requests: BUG-015, BUG-013. State: verified locally; Git persistence pending.

Reject incomplete cached model files and remove the race caused by monkeypatching Hugging Face process-global download functions.

## Steps and verification

1. Reproduce the one-byte file false positive; use trusted expected hash/size or format validation and atomic temporary downloads.
2. Reproduce two concurrent downloads overlapping; replace global `hf_fd.http_get` mutation with a scoped, concurrency-safe mechanism.
3. Test corrupted/interrupted download recovery and parallel callbacks; avoid live model downloads in unit tests, then smoke one real small artifact.

## File-Level Plan

- `videotrans/util/help_down.py`: remove process-global `hf_fd.http_get` monkeypatch and use per-call `tqdm_class` callbacks. Validate cached/downloaded files against an explicit or URL SHA-256, trusted size, or remote Content-Length; store atomic SHA-256 sidecars for future offline validation. Keep downloads on temporary files until verified and handle Range responses safely.
- `tests/test_help_down.py`: create response/session fixtures for one-byte cache, valid cache, truncation, and atomic replacement; run overlapping Hugging Face requests and verify callbacks never cross and `http_get` remains unchanged.
- BUG request files: append actual reproduction and verification; keep open until git persistence/release gates pass.

## Best practices

- Never infer completeness from `size > 0`; require trusted metadata and verify before replacing a valid file.
- Avoid global monkeypatching in concurrent network code; callbacks must be scoped to each request.
- Make interrupted downloads resumable without appending a mismatched server range.
