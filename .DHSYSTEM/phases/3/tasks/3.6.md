## Steps and verification

1. Trace Docker host environment, CLI flags and credential handling; make container startup reach port 7860 with credentials and update its exact command in docs.
2. Resolve bundled assets against the frozen resource root and writable cache/config/output against user data, including existing-data migration where needed.
3. Smoke Docker from host; launch extracted Windows GUI from another CWD in a read-only install directory, close/reopen, and verify user data location.

## File-Level Plan

- `Dockerfile`: pass explicit network host and port to WebUI entry point; keep credentials supplied only at container runtime.
- `webui.py`: retain loopback default and existing network-auth guard; expose the same behavior from the Docker command.
- `docs/webui.md`: show a working authenticated Docker command and file-level config mounts instead of mounting over the package's `videotrans` source.
- `videotrans/configure/_paths.py`: split bundled read-only resources from frozen writable user data, copy missing static resources/config once, and redirect model/cache/log and FFmpeg lookup correctly.
- `videotrans/configure/_app_settings.py`: map only the old default output location to user data after frozen migration, preserving explicit custom output locations.
- `sp.py`: load splash/QSS/icon from bundled resource path and log to the writable log directory, independent of CWD.
- `sp.spec`: verify bundled data layout matches the resource resolver; change only if needed.
- `videotrans/process/stt_funasr.py`: resolve the filename-loaded FunASR helper from the read-only bundle.
- `tests/test_webui_access.py`, `tests/test_frozen_paths.py`: test Docker entry/auth contract and isolated frozen path migration without mutating real user data.
- BUG request files: append evidence; do not close until extracted artifact and container smoke pass.

## Best practices

- Keep secrets out of image layers; require runtime credentials for non-loopback binding.
- Never write into the frozen executable directory. Preserve user files during migration.
- Resolve assets by bundle root, not process CWD; keep source checkout behavior unchanged.
