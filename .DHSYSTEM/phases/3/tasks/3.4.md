## File-Level Plan

- `videotrans/configure/_app_params.py`: merge persisted dictionary into defaults only for compatible values, and merge F5 role lines deterministically. Do not overwrite valid legacy choices or write to the real user config during tests.
- `.dockerignore`: exclude user JSON config, environment files, private keys, generated media, model/cache data, and local test state from `COPY . .`.
- `tests/test_app_params.py`: create isolated legacy-config tests for missing/invalid fields, preserved valid fields, and F5 custom roles. Check the Docker context policy with representative seeded filenames.
- `.DHSYSTEM/requests/BUG-012.md`, `.DHSYSTEM/requests/BUG-014.md`: record verification evidence; close only after both the behavior and the Docker image have been checked.

## Best practices

- Keep backward-compatible config keys and preserve unknown keys until a separate migration policy exists.
- Prefer explicit type checks at the load boundary; avoid broad exception handling that hides programming errors.
- Keep secrets outside build context; do not print secret contents in test output.
