# Task 9.1 — ResultPanel with in-app playback

## Objective

Add a reusable result panel that plays the finished video, lists output files and offers Open folder, Open in external player and Translate another video, and show it when a job completes.

## Paths

```text
videotrans/ui/result_panel.py
videotrans/mainwin/_actions_task.py
videotrans/language/vi_VN.json
videotrans/language/en_US.json
tests/test_result_panel.py
```

## Work

- Build `ResultPanel(QWidget)` with `load_receipt(receipt: dict)`, play/pause, seek, time labels, volume and fullscreen.
- List video, source/target SRT, ASS (Phase 11) and dubbed audio with sizes.
- Actions: `QDesktopServices.openUrl` for folder and external player; a `translate_another` signal for the caller.
- After the existing `output_receipt` handling in `_actions_task.py`, show the panel for the finished job (single job: auto-open; batch: list, see 10.3).

## File-Level Plan

- `videotrans/ui/result_panel.py` — widget, no task or FFmpeg logic.
- `videotrans/mainwin/_actions_task.py` — hand the parsed receipt to the panel; keep `format_output_receipt` text output.
- Locale catalogs — panel labels and missing-file message.
- `tests/test_result_panel.py` — offscreen tests for receipt loading, missing file state and action signals (no real playback).

## Best Practices

- Stop and release the player (`setSource(QUrl())`) when the panel hides, so Windows does not lock the output file.
- Keep keyboard access: Space toggles play, arrows seek, Esc leaves fullscreen.

## Acceptance

- Panel loads any existing receipt, shows files and actions, and handles a missing file without exceptions.
