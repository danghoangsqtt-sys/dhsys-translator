# Task 11.2 — Pipeline integration and font bundling

## Objective

Use the caption style module in the hard-subtitle path, export the styled `.ass`, and bundle a Vietnamese-complete font for libass.

## Paths

```text
videotrans/task/_stage_subtitle.py
videotrans/task/_stage_assemble.py
videotrans/task/taskcfg.py
videotrans/configure/_app_params.py
videotrans/styles/fonts/BeVietnamPro-*.ttf
videotrans/styles/fonts/OFL.txt
sp.spec
cli.py
tests/test_caption_pipeline.py
tests/test_subtitle_output_media.py
```

## Work

- Add `caption_style` to task config and params (default `classic`); CLI flag `--caption_style`.
- In `_process_subtitles`, when the style is animated: build cues from the final SRT(s), call `build_ass`, write `cache/end.ass` and a copy `target_dir/<target>.ass`, force `subtitle_type` 1/3 (hard) and record the switch in the receipt.
- In `_get_hard_cfg` / subtitle filters, add `fontsdir` pointing to the bundled fonts (escape Windows paths for the filter graph).
- Add the font files and license to the repo and `sp.spec` datas; record them in the distribution license inventory.

## Best Practices

- Keep the `classic` path untouched and covered by a byte-equality test.
- Escape `:` and `\` in FFmpeg filter paths on Windows.

## Acceptance

- A real 8–10 s fixture job with `karaoke` produces an MP4 whose decoded frames show the accent colour moving across words (pixel check at two timestamps) and a matching `.ass` in the output folder.
- `classic` output unchanged.
