# Task 11.1 — Caption styles, word timing and ASS builder

## Objective

Create a pure, fully tested module that turns SRT cues into animated ASS for the karaoke, box and bilingual styles.

## Paths

```text
videotrans/util/caption_styles.py
tests/test_caption_styles.py
```

## Work

- Dataclasses `Cue(start_ms, end_ms, text, words=None)` and `CaptionStyle(kind, font, size, accent, base, position)`.
- `estimate_word_timings`: weight per word = syllable count (Vietnamese/space-separated) or character count; distribute in centiseconds so the sum equals the cue duration exactly; minimum 8 cs per word.
- `build_ass`: `[Script Info]` with `PlayResX/Y` from the video size, `[V4+ Styles]` for main/accent/source, `[Events]` dialogue lines; escape `{`, `}` and `\` in user text; wrap long lines with existing `simple_wrap` rules.
- Size defaults scale with video height (e.g. 5.5% of height for main text).

## Best Practices

- `\kf` durations are centiseconds; round with carry so rounding never drifts past the cue end.
- Keep the module free of Qt, params and file I/O.

## Verification

```powershell
uv run --python 3.12 pytest -q tests/test_caption_styles.py
```

Tests cover: timing sums, minimum durations, real-timestamp passthrough, escaping, each style's ASS headers/events, Vietnamese diacritics preserved, bilingual ordering.

## Acceptance

- Deterministic output for fixed input; golden ASS snapshots for each style.
