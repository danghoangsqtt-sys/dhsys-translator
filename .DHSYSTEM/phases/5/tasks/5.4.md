## File-Level Plan

- `installer/pyvideotrans.iss`: per-user installer by default, optional Start/Desktop shortcuts, upgrade identity, uninstaller and program/data separation. Preserve `%LOCALAPPDATA%\pyVideoTrans` data by default on uninstall.
- `scripts/build_local_distribution.ps1`: validate candidate layout/hash/license inventory, create deterministic artifact names, build ZIP with `tar.exe`, invoke a pinned/validated Inno Setup compiler when available, and emit SHA-256 sidecars plus a compact manifest.
- `scripts/verify_local_distribution.ps1`: verify checksums, archive contents, executable/resources, prohibited files and installer metadata without GitHub.
- `tests/test_distribution_manifest.py`: prevent credentials, local config, logs, caches, downloaded models, private media and build-machine absolute paths from entering artifacts.
- Measure and report the current roughly 6.16 GiB onedir composition. Any Core/optional component split must preserve provider/model IDs and replace missing optional binaries with an explicit readiness/install path rather than hiding a provider or crashing at import time.
- Docs: recipient instructions, SmartScreen/code-signing expectations, CPU/GPU distinctions and support-report workflow.

## Best Practices

- Generated `release/local/` output is gitignored; only scripts/spec/docs are committed.
- Bundle Python, Qt and FFmpeg inside the app; do not mutate global PATH.
- Include GPL/project licenses and third-party notices required by bundled components.
- Do not download mutable build inputs without a pinned version and verified hash/signature.

## Acceptance

1. One local command produces portable ZIP, Setup.exe, manifest and SHA-256 files from the current verified candidate.
2. The portable ZIP runs after extraction to a new path with Python absent from PATH.
3. Setup installs for the current user, shortcuts launch the app, upgrade preserves settings, and uninstall preserves user data by default.
4. Neither artifact contains credentials, user config, logs, caches, downloaded models or personal media.
5. Verification fails clearly on a changed/missing file, incorrect checksum or unavailable installer compiler.
6. Artifact size and largest components are reported; any optional split passes provider-registry and frozen-menu compatibility tests.
